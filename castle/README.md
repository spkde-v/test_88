# Castle: замок в тумане, вороны, гроза

12 секунд, 1920×1080, 60 fps, без звука: `castle.mp4`. Кадр с молнией: `castle-lightning.png`, раскадровка: `contact-sheet.png`.

Основа — фотография замка `refs/castle.webp`. Туман, вороны, молнии, дождь и огонёк в окне анимированы поверх неё.
Ворон — кукла из `refs/raven3.png`: тело и крыло, крыло машет, «проворачиваясь» через линию плеча
(вверх → ребром → вниз), кончики перьев отстают на ударе вниз; второе, дальнее крыло идёт чуть позади.

| Время | Что происходит |
|---|---|
| 0–1.8 с | сплошной клубящийся туман |
| 0.8–4.8 с | туман расходится: сначала шпили, потом стены и склоны; камера едва заметно наезжает на замок (весь ролик) |
| 3.0–6.9 с | справа влетают три ворона: крупный на переднем плане, средний облетает шпиль, дальний за туманом |
| 5.8–7.1 с | небо темнеет, туман густеет |
| 7.2 с | первая, дальняя молния справа за замком |
| 8.5 с | вторая, близкая: небо вспыхивает, замок — чёрный силуэт; с башен срываются четыре ворона |
| 8.45–12 с | косой дождь, редкие дальние вспышки в облаках (10.25 и 11.35 с) |
| 10.4–12 с | в окне главной башни загорается и мерцает тёплый огонёк |

```
pip install pillow numpy opencv-python-headless scipy imageio-ffmpeg
python3 castle.py render castle --fps 60
python3 castle.py still 8.51 castle-lightning.png
python3 castle.py sheet 0:11.5:0.5 contact-sheet.png
python3 castle.py raven out/raven.png      # один взмах ворона
```

Каждый кадр вычисляется только из времени `t`. Тайминги — константы `T_*`, `BOLTS`, `FLICKERS`, пути воронов — `FLIGHTS` в `castle.py`.
