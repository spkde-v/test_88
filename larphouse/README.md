# Larphouse — анимация готической надписи

5 секунд, 1920×1080, 60 fps, **прозрачный фон**:

- `larphouse.webm`: VP9 с альфа-каналом (подходит для веба, OBS, DaVinci, After Effects через плагин);
- `larphouse.mov`: ProRes 4444 с альфа-каналом, для монтажных программ. Весит около 290 МБ и не хранится в git, его создаёт команда `render` ниже;
- `larphouse-preview.mp4`: предпросмотр на светлом фоне, без прозрачности;
- `larphouse-final.png`: финальный кадр с прозрачностью; `contact-sheet.png`: раскадровка на светлом фоне.

Буква L, угловые орнаменты, меч с розами и кот взяты с референсов в `refs/`.
Строчные «arphouse» набраны шрифтом UnifrakturCook Bold (лицензия OFL). Поверх шрифта
добавлена гравировка: светлая фаска со штриховкой точками, в той же манере, что у буквы L.
Светлые места гравировки прозрачные: сквозь них виден фон, на который кладётся видео.

| Время | Что происходит |
|---|---|
| 0.5–2.9 с | буквы слева направо проступают, как чернила сквозь бумагу: бледное размытое пятно темнеет и становится резким; завитки L разворачиваются от ствола |
| 0.0–4.75 с | угловые лозы растут от углов вдоль стеблей; у каждого угла своё начало, длительность и характер проявления (верхний правый 0.0–3.7 с, нижний правый 0.25–4.25 с, верхний левый 0.45–4.75 с, нижний левый 0.6–4.1 с) |
| 2.2–4.2 с | меч с розами прорисовывается от рукояти к острию, цветы наливаются красным |
| 1.0–2.85 с | справа рысью вбегает кот (вырезанная кукла из `cat-scared.png`: лапы качаются вокруг бедра, шерсть сглажена) и резко тормозит |
| 3.0–3.2 с | кот замечает распустившуюся розу, шерсть встаёт дыбом (форма перетекает в оригинальный взъерошенный силуэт) |
| 3.2–3.62 с | испуганный прыжок в позе из `cat-jump.png`, тень на земле уменьшается |
| 3.62–4.3 с | приземляется, разворачивается и удирает вправо за кадр |
| до 5.0 с | финальная композиция, «дышит» только зернистость краски |

```
pip install pillow numpy opencv-python-headless scipy imageio-ffmpeg
python3 larphouse.py render larphouse --fps 60   # → larphouse.mov, .webm, -preview.mp4
python3 larphouse.py still 4.99 larphouse-final.png
python3 larphouse.py sheet 0.2:4.9:0.313 contact-sheet.png
python3 larphouse.py frames out/frames --fps 30 --light --no-corners   # прозрачные RGBA PNG для сайта
python3 larphouse.py corners out/corners --light                       # спрайты роста угловых лоз
```

Для тёмного фона: `--light` печатает буквы, лозы и меч светлой краской цвета бумаги, красные розы
и кот остаются как были. `--no-corners` убирает угловые лозы из кадров, а `corners` сохраняет их
отдельно: для каждого угла сетка из 40 стадий роста (8 в ширину, ячейка 288×372), в порядке и с
таймингами `T_CORNERS`. Так страница может ставить лозы в углы экрана при любом разрешении — см.
компонент `../larphouse-void/react/LarphouseVoid.jsx`.

Каждый кадр вычисляется только из времени `t`, случайный шум зафиксирован сидами, поэтому
любой кадр можно отрендерить отдельно. Тайминги задаются константами `T_*` в начале `larphouse.py`.
