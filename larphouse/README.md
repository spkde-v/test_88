# Larphouse — анимация готической надписи

6.5 секунды, 1920×1080, 60 fps, **прозрачный фон**:

- `larphouse.webm`: VP9 с альфа-каналом (подходит для веба, OBS, DaVinci, After Effects через плагин);
- `larphouse.mov`: ProRes 4444 с альфа-каналом, для монтажных программ. Весит около 290 МБ и не хранится в git, его создаёт команда `render` ниже;
- `larphouse-preview.mp4`: предпросмотр на светлом фоне, без прозрачности;
- `larphouse-final.png`: финальный кадр с прозрачностью; `contact-sheet.png`: раскадровка на светлом фоне.

Буква L, угловые орнаменты, меч, обвитый цветущей лозой (`sword-flowers.webp`, карандашный рисунок:
бумага и фоновые штрихи убраны, клинок, гарда и рукоять непрозрачные), и роза (с меча с розами) взяты
с референсов в `refs/`. Кот (`cat-*.png`, класс `Cat`) в этой версии выключен: `SHOW_CAT = False`.
Строчные «arphouse» набраны шрифтом UnifrakturCook Bold (лицензия OFL). Поверх шрифта
добавлена гравировка: светлая фаска со штриховкой точками, в той же манере, что у буквы L.
Светлые места гравировки прозрачные: сквозь них виден фон, на который кладётся видео.

| Время | Что происходит |
|---|---|
| 0.45–2.9 с | **все буквы начинают проявляться одновременно**: чернила растекаются по штрихам каждой буквы от её самого толстого места (у L — от середины ствола вверх, вниз и по всем завиткам), сначала середина штриха, потом края, с мокрой кромкой впереди; у каждой буквы свой темп, все готовы к 2.9 с; на лилии L в конце вспыхивает блик |
| 0.0–4.75 с | угловые лозы растут от углов вдоль стеблей; у каждого угла своё начало, длительность и характер проявления (верхний правый 0.0–3.7 с, нижний правый 0.25–4.25 с, верхний левый 0.45–4.75 с, нижний левый 0.6–4.1 с) |
| 2.45–2.95 с | над правой половиной слова чернилами проявляется меч, остриём влево |
| 2.95–3.1 с | замах: меч отводится вправо и поднимает остриё |
| 3.1–3.4 с | **удар**: меч ныряет на линию разреза и остриём вперёд прорезает всё слово справа налево (смаз движения из 48 подкадров); за ним тёмный серп следа с яркой щелью, кадр трясётся, из разреза летят чернильные брызги |
| 3.2–3.8 с | верхняя половина слова соскальзывает по разрезу влево и чуть приподнимается (с отдачей); кромка разреза неровная, как от настоящего лезвия |
| 3.47–4.4 с | меч возвращается: широкой дугой через верх (остриё проходит слева через «вверх» направо, со смазом движения) и с лёгким перелётом ложится горизонтально над надписью по центру экрана; там и остаётся до конца |
| 3.3–5.0 с | **срез кровоточит** с обеих сторон: красный кант по кромкам, капли висят с верхней кромки, потёки бегут вниз по штрихам нижней половины |
| 3.65–6.2 с | из щели прорастают тернистые стебли с листьями, по два усика тянутся вдоль разреза; на концах стеблей набухают красные бутоны и по очереди, справа налево, раскрываются 4 розы |
| до 6.5 с | финальная композиция, «дышит» только зернистость краски |

Разрез почти горизонтальный (5°), чтобы пройти через всё слово от L до «e». Линия, сдвиг половин,
тайминги удара и роз — константы `CUT_*`, `SLIDE`, `T_SWORD_IN`…`T_CUT`, `ROSE_*` в `larphouse.py`,
капли и места роз вычисляются там, где линия разреза пересекает буквы (`Slash.sites`).

```
pip install pillow numpy opencv-python-headless scipy imageio-ffmpeg
python3 larphouse.py render larphouse --fps 60   # → larphouse.mov, .webm, -preview.mp4
python3 larphouse.py still 6.49 larphouse-final.png
python3 larphouse.py sheet 0.3:6.5:0.3875 contact-sheet.png
python3 larphouse.py frames out/frames --fps 30 --light --no-corners   # прозрачные RGBA PNG для сайта
python3 larphouse.py corners out/corners --light                       # спрайты роста угловых лоз
```

Для тёмного фона: `--light` печатает буквы, лозы, рапиру и стебли светлой краской цвета бумаги,
кровь и красные розы остаются как были. `--no-corners` убирает угловые лозы из кадров, а `corners` сохраняет их
отдельно: для каждого угла сетка из 40 стадий роста (8 в ширину, ячейка 288×372), в порядке и с
таймингами `T_CORNERS`. Так страница может ставить лозы в углы экрана при любом разрешении — см.
компонент `../larphouse-void/react/LarphouseVoid.jsx`.

Каждый кадр вычисляется только из времени `t`, случайный шум зафиксирован сидами, поэтому
любой кадр можно отрендерить отдельно. Тайминги задаются константами `T_*` в начале `larphouse.py`.
