# Seraph: полёт шестикрылого ангела

7 секунд, 1920×1080, 60 fps, **прозрачный фон**:

- `seraph.webm`: VP9 с альфа-каналом;
- `seraph.mov`: ProRes 4444 с альфа-каналом (большой файл, не хранится в git, его создаёт команда `render`);
- `seraph-preview.mp4`: предпросмотр на светлом фоне;
- `seraph-hover.png`: кадр зависания с прозрачностью; `contact-sheet.png`: раскадровка.

Ангел взят прямо с референса `refs/seraph.png` и разрезан на куклу: неподвижное тело (диск с глазом,
шея, «хвостик» между нижними крыльями) и шесть крыльев, которые поворачиваются вокруг своих корней.
Под передними частями задние крылья продолжены перьями того же крыла, поэтому при взмахе не открываются дыры.

| Время | Что происходит |
|---|---|
| 0.0–0.3 с | пустой кадр |
| 0.3–3.0 с | ангел влетает из правого нижнего угла и по плавной дуге поднимается вверх, замедляясь; слегка наклоняется по ходу движения |
| 3.0–5.2 с | зависает справа вверху и пристально смотрит влево: центральный глаз переводит взгляд влево и держит его, зрачок лишь чуть подрагивает, веки слегка прищурены, один раз он вглядывается чуть выше; глаза на крыльях тоже смотрят влево, каждый со своими мелкими движениями; тело наклоняется влево (до 8°) и подаётся в ту сторону; в конце взгляд возвращается к зрителю и ангел моргает |
| 5.2–5.52 с | глубокий медленный взмах, тело приседает |
| 5.52–6.25 с | рывок вверх за кадр с ускорением |
| до 7.0 с | догорают падающие перья |

Крылья бьют волной (верхние чуть впереди, средние и нижние с запаздыванием), удар вниз быстрее подъёма,
на каждом ударе тело слегка подбрасывает. Частота взмахов меняется плавно (фаза интегрируется по времени).
Размытие движения сделано честно: каждый кадр усредняет 5 подкадров внутри выдержки 180°.
За ангелом слабое тёплое свечение, во время полёта он роняет несколько перьев.

```
pip install pillow numpy opencv-python-headless scipy imageio-ffmpeg
python3 seraph.py render seraph --fps 60     # → seraph.mov, seraph.webm, seraph-preview.mp4
python3 seraph.py still 4.3 seraph-hover.png
python3 seraph.py cycle out/cycle.png        # один взмах отдельно, на светлом и тёмном фоне
python3 seraph.py sheet 0.2:6.8:0.44 contact-sheet.png
```

Каждый кадр вычисляется только из времени `t`. Тайминги задаются константами `T_*`, путь `RISE_PATH`,
амплитуды взмахов `AMP` в начале `seraph.py`.
